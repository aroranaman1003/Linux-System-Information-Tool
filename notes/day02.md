# Day 2

## Commands Learned

### whoami
Shows current logged in user.

### clear
Clears terminal screen.

### cat
Displays file contents.

### cp
Copies files.

### rm
Removes files.

### sudo
Runs commands with elevated privileges.

### which
Shows location of a command.

## Key Learnings

- Use sudo when elevated permissions are needed.
- Commands are stored in directories like /bin and /usr/bin.
