# Day 9

## User Management

### who

Shows logged in users.

### adduser

Creates a new user.

### useradd

Low-level command to create users.

### passwd

Sets or changes user password.

### usermod

Modifies user accounts.

### userdel

Deletes users.

## Group Management

### groupadd

Creates a new group.

### groupdel

Deletes a group.

### gpasswd

Adds/removes users from groups.

## Privilege Management

### sudo

Runs commands with elevated privileges.

### su

Switch to another user.

### visudo

Safely edits the sudoers file.

## Important Files

### /etc/passwd

User account information.

### /etc/shadow

Encrypted password information.

### /etc/group

Group information.

## Key Learnings

- Every user has a primary group.
- Not every user can use sudo.
- Follow the Principle of Least Privilege.
